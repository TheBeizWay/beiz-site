# Notes the daily site agent reads

- `buyer-language.md`: exact words prospects use on calls and in replies. One line each: date, who (role, not name), the phrase.
- `reddit-digest.md`: paste the Monday Reddit digest here. The agent may use recurring pains as copy ideas, never as statistics or quotes on the site.

The agent never names or quotes anyone publicly, and every site change goes through a pull request Purav approves.
